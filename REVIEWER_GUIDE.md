# Reviewer guide — from each point of the first-round review to the evidence (manuscript revision 16)

Everything referenced below is in this repository. "Export" = `data/export/` (anonymised copy of the platform export of 2026-10-01; participant identifiers random, timestamps relative, rare roles aggregated — see `ANONYMISATION.md`). Values recomputed by the audit are in `audit/outputs/`; the comparison with the manuscript, value by value, is `audit/history/RIPRODUZIONE_PRECEDENTI.csv`. New analyses are post-review and exploratory (their specifications were written before running them: `audit/outputs/SPEC_direzione_aggiustata.json`, `audit/PROTOCOLLO_CAPTION_CONTROLLATE.md` §4).
